# Smart Power Management System

IoT-based power outage detection and targeted SMS notification system using ESP32, Node.js, Firebase Realtime Database, and SIM800L GSM Module.

## Project Structure
- `firmware/` - ESP32 firmware code (C++ / Arduino / PlatformIO)
- `backend/` - Node.js backend listener and outage decision logic
- `dashboard/` - Real-time web dashboard (HTML/CSS/JS)
- `docs/` - Project documentation (`project_info.md`, `ai_prompts.md`)
